# Архитектурное рабочее пространство

Интерактивный прототип веб-приложения для проектирования зданий. Постоянное название пока не выбрано; в шапке оставлен геометрический логотип.

**Сайт:** https://roman33r.github.io/BIM/

## Возможности первой версии

- Светлый интерфейс и дополнительная тёмная тема.
- Создание пустых проектов и переключение между ними через «Мои проекты».
- План этажа, интерактивный 3D-вид и разделённый экран.
- Навигация по этажам, добавление этажа копированием верхнего.
- Выбор и перетаскивание стен, проёмов, плит, мебели, помещений и размеров на плане и в 3D; редактирование координат.
- Список всех элементов для выбора перекрытых объектов; точное перемещение стрелками на 50 мм, с Shift — на 500 мм.
- Создание стен, размещение дверей и окон с проверкой границ и пересечений.
- Построение полигонального перекрытия, двухточечные размеры.
- Создание прямоугольных помещений и добавление мебели из библиотеки.
- Отмена/повтор, копирование и удаление.
- Локальное сохранение, импорт/экспорт JSON, векторный SVG, печать/PDF через браузер.

Это прототип: 3D показывает выбранный этаж, контуры помещений задаются вручную, размеры являются независимыми обозначениями. Мебель — отдельные объекты модели. Отсечка — горизонтальное ограничение высоты стен, а не выпуск строительного разреза. Полноценные BIM-расчёты, IFC, серверное хранение и совместное редактирование ещё не реализованы. Печатная схема не является рабочей документацией; её масштаб зависит от настроек печати.

Проекты сохраняются раздельно в `localStorage` конкретного браузера. Новый проект создаётся в меню рядом с названием текущего проекта; предыдущие доступны там же через «Мои проекты». Для передачи между устройствами скачайте JSON и откройте его на другом устройстве. При блокировке хранилища показывается предупреждение. Одновременная работа в нескольких вкладках не поддерживается.

## Выделение и перемещение

В режиме «Выбор» перетащите объект мышью. На плане удерживайте пробел для панорамирования. В 3D используйте Shift + перетаскивание для вращения камеры, чтобы не двигать объект. Двери и окна перемещаются вдоль своей стены с ограничениями у соседних проёмов и краёв; перенос стены сохраняет положение её проёмов относительно стены. Один перенос — одно действие отмены. Esc во время переноса возвращает исходное положение.

Слева раскройте «Все элементы», если нужный объект перекрыт другим. Положение можно задать в свойствах через X/Y или клавишами стрелок. Новые помещения создаются инструментом «Зона», мебель добавляется из библиотеки.

## Локальный запуск

Нужен Python 3. Из корня репозитория:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173. Для 3D нужен WebGL. Все файлы Three.js включены в репозиторий; загрузок с CDN при работе приложения нет.

## Проверки

Нужен Node.js 24:

```sh
node --test
node --check app.js
node --check plan.js
node --check scene.js
```

## Публикация

GitHub Pages использует `.github/workflows/pages.yml`. Каждое изменение в `main` проходит проверки и публикует только файлы приложения. В настройках репозитория источник Pages должен быть **GitHub Actions**.

## Структура

- `index.html`, `styles.css` — оболочка интерфейса и адаптивные стили.
- `model.js` — схема проекта, геометрия, проверка импорта и размещения проёмов.
- `elements.js` — идентификаторы, миграция прежних проектов и общие операции перемещения.
- `project-store.js` — каталог локальных проектов и атомарное сохранение.
- `app.js` — взаимодействие, команды, история, локальное сохранение и экспорт.
- `plan.js` — векторный план и его экспорт.
- `scene.js` — построение и навигация 3D-модели.
- `furniture-plan.js`, `furniture-scene.js` — связанные 2D/3D-представления мебели.
- `assets/logo.svg` — логотип без текстового названия.
- `vendor/` — Three.js **0.180.0**, лицензия MIT в `THREE-LICENSE.txt`.
- `docs/` — план развития и дизайн.

В репозиторий не следует добавлять токены доступа и конфиденциальные проекты: репозиторий и Pages публичные.
