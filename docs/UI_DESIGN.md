# Принятое направление интерфейса

- Светлая тема — основная; белый план, нейтральные панели, синий акцент выбранного элемента.
- Геометрический логотип сохранён как самостоятельный SVG. Текстовое название системы отсутствует до выбора бренда.
- Навигатор проекта слева, инструменты на отдельной вертикальной полосе.
- Центральные режимы: план, 3D, разделённый экран с общим выбором объекта.
- Свойства справа: параметры конкретного объекта, связанные с моделью.
- Плотность интерфейса адаптируется под ширину окна. На узких экранах скрывается навигатор, на телефоне — панель свойств; полноценное редактирование рассчитано на компьютер.
- Сохранение обозначено как локальное; элементы интерфейса не имитируют сервер или совместную работу.

Реализация первой версии — статическое приложение с собственным векторным планом и 3D-геометрией из тех же параметров. Растровый концепт не используется вместо работающего редактора.
