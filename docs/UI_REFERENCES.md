# Референсы интерфейса веб-САПР

Подготовлено 18 ноября 2026 года. Ниже реальные интерфейсы аналогов; это визуальные ориентиры, а не макеты нашего приложения. Скриншоты относятся к разным версиям продуктов.

## 1. Archicad — структура профессионального проекта

![Рабочее пространство Archicad](https://www.graphisoft.com/content/uploads/2026/01/Customizing-Your-Archicad-Work-Environment.jpg)

[Источник: Graphisoft Events](https://www.graphisoft.com/events). [Обзор интерфейса Graphisoft](https://community.graphisoft.com/t5/Getting-started/The-Archicad-interface/ta-p/303976).

Использовать как ориентир: дерево этажей, видов и листов; центральный план; инструменты построения; быстрый доступ к параметрам и масштабу. Для нашего первого экрана оставить доступным набор основных инструментов, остальные показывать по контексту.

## 2. Snaptrude — основной ориентир браузерного редактора

![Редактор Snaptrude, пример из публикации о версии 2.6.2](https://assets-global.website-files.com/63ea37f826113a5029824f10/65e1ecedb3442b4bad57d8e8_snaptrude-2_6_2-website.png)

[Источник: публикации Snaptrude](https://www.snaptrude.com/product-releases). [Руководство по интерфейсу и работе](https://help.snaptrude.com/en/articles/17761283-getting-started-with-snaptrude).

Использовать как ориентир: компактная верхняя панель, большой viewport, контекстные свойства справа, навигация по этажам и работа с 3D. Скриншот иллюстрирует компоновку одной из предыдущих версий.

## 3. Floorplanner — понятное построение плана

![Интерфейс Floorplanner](https://static.floorplanner.com/_next/static/media/home-image-01Retina.1rab_7qjzk8g8.png)

[Источник: Floorplanner](https://floorplanner.com/).

Использовать как ориентир: наглядные категории объектов, чистое поле плана, различимые инструменты и простой переход к 3D.

## Предлагаемая компоновка нашего интерфейса

- Верхняя полоса: название проекта, статус сохранения, отмена/повтор, доступ и экспорт.
- Слева: вертикальная полоса основных инструментов и сворачиваемое дерево «Этажи / Виды / Листы».
- Центр: поле плана с сеткой и размерами; режимы «План / 3D / Разделённый экран».
- Справа: свойства выбранного элемента; вкладки библиотеки и замечаний.
- Нижняя строка: координаты, масштаб, единицы, привязки и подсказка текущей команды.

Визуальное направление: светлые нейтральные панели, белый чертёж, тонкие границы, один синий акцент для выбора и активных инструментов. Числовые поля и подписи на русском языке. Рабочее название до выбора бренда — «САПР».

Первый макет: план первого этажа двухэтажного дома, выделенная стена с редактируемой толщиной и высотой, дерево этажей слева и переключатель 3D над рабочим полем. Следующее состояние — та же модель в 3D с сохранением выбора объекта.
